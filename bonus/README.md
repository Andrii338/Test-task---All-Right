# Генератор Playwright-тестів для SauceDemo

Опишіть кроки та спостережуваний результат українською або англійською у текстовому файлі. Headless Codex перетворить опис на послідовність дій і перевірок. Скрипт перевірить план і запише Playwright-сценарій у `tests/generated/<назва-файлу>.spec.ts`. Логін використовує наявний клас `Shop`.

## Як запустити

Виконайте команди з кореня репозиторію після `npm ci` та `npx playwright install chromium`. Для генерації потрібні встановлений Codex CLI з командою `codex exec`, активний вхід через `codex login` і доступ до моделі. Стан входу показує `codex login status`.

```bash
npm run generate -- bonus/cases/backpack-details.txt --run
npm run generate -- bonus/cases/continue-shopping.txt --run
```

Параметр `--run` одразу запускає новий файл у Chromium і повертає код завершення Playwright. Без нього команда лише генерує тест. Повторна генерація однойменного кейсу замінює попередній файл після перевірки нового плану. Назва вхідного файлу має складатися з малих латинських літер, цифр і дефісів.

Обидва готові приклади можна виконати командою `npm run test:generated`. На кожен push GitHub Actions перевіряє типи і виконує збережені тести разом з основним набором. Для цього запуску достатньо Chromium і залежностей репозиторію. [Запуски CI](https://github.com/Andrii338/Test-task---All-Right/actions/workflows/playwright.yml)

## Приклади

| Вхід | Згенерований тест | Що перевіряється |

| [Картка рюкзака](cases/backpack-details.txt) | [backpack-details.spec.ts](../tests/generated/backpack-details.spec.ts) | Назва й ціна $29.99 у картці, повернення в каталог із шістьма товарами |
| [Повернення з кошика](cases/continue-shopping.txt) | [continue-shopping.spec.ts](../tests/generated/continue-shopping.spec.ts) | Один Bike Light у кошику, заголовок Products і лічильник 1 після Continue Shopping |

Приклади згенеровано двома окремими викликами Codex CLI з моделлю `gpt-6.1-sol`. Обидва тести пройшли в Chromium з першої спроби без ручних правок. Перевірка картки рюкзака тривала 953 мс, повернення з кошика — 987 мс. [Протокол GitHub Actions](https://github.com/Andrii338/Test-task---All-Right/actions/runs/45465290086/job/138698473360) · [Архів звіту](https://github.com/Andrii338/Test-task---All-Right/actions/runs/45465290086/artifacts/14955441085). Версія CLI під час підготовки прикладів — `0.171.0-alpha.13`. Повторний виклик може дати іншу назву тесту або іншу послідовність кроків. Порівнюйте отримані перевірки з очікуваним результатом кейсу.

## Підтримувані сценарії

Генератор підтримує вхід як standard_user, кліки в каталозі, картці й кошику та перевірки точного тексту й кількості елементів. Наприклад, очікування «шість товарів» перетворюється на `toHaveCount(6)`. Перелік локаторів і підтримуваних операцій визначено в [generate.mjs](generate.mjs). Для нового типу дії, наприклад вибору сортування, спочатку розширте перелік операцій. Невідомий локатор, непідтримуваний крок або відсутність перевірок завершують генерацію з помилкою.
