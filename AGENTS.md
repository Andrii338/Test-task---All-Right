# Інструкції для агента

Мета: виконати Middle QA Automation assignment для SauceDemo і Restful Booker.

- TypeScript strict, Playwright Test для UI та API; Chromium для UI.
- 6 основних і 3 негативні UI-тести; один повний API lifecycle і 3 негативні API-кейси.
- Кожен тест незалежний. Не використовувати чужі booking ID та збережений спільний кошик.
- Створені API-дані прибирати у fixture teardown, зокрема після падіння тесту.
- Використовувати data-test або доступні ролі. Без waitForTimeout, XPath і force click.
- Перед перевіркою сортування перевіряти кількість елементів. Суми порівнювати в центах.
- Не вигадувати HTTP-коди, DOM, баги, результати запусків або втручання людини.
- Звіряти API-контракт з https://restful-booker.herokuapp.com/apidoc/ і реальним сервісом.
- Відомі дефекти відтворювати окремо, з поясненням test.fail; помилки середовища не маскувати.
- Запустити typecheck і всі тести. Зберегти фактичні команди, результати та виправлення в AI_WORKLOG.md.
- README українською, ідентифікатори та назви тестів англійською.
- CI: push, pull_request, workflow_dispatch; звіт завантажувати навіть після падіння тестів.
- Для бонусу використовувати headless Codex. Зберігати текстові приклади й згенеровані тести.
- Не додавати node_modules, токени або .env у репозиторій.
